# BEBE_Responsive_Project

```text
영유아 쇼핑몰 BEBE를 반응형 웹사이트로 구현하였습니다.

> 영유아 의류와 육아용품을 편리하게 탐색할 수 있도록 상품 정보 구조와 UI/UX를 구성
> 연령별·상황별 상품 추천과 직관적인 화면 구성을 통해 사용자의 쇼핑 편의성 향상
```

## 🖥️ 프로젝트 소개

### 개발 배경

```text
육아용품과 영유아 의류에 대한 관심이 높아지면서
다양한 상품을 비교하고 선택할 수 있는 쇼핑 환경의 중요성이 커지고 있습니다.

이에 영유아를 키우는 부모가 필요한 상품을 편리하게 탐색하고,
합리적인 가격으로 구매할 수 있도록 BEBE 쇼핑몰을 기획하고 구현하였습니다.
```

### 프로젝트 목표

```text
복잡하지 않고 깔끔한 디자인을 바탕으로 상품 정보를 직관적으로 제공하고,
연령별·상황별 추천과 코디 상품 구성을 통해 상품 선택의 부담을 줄이는 것을 목표로 하였습니다.

또한 PC와 Mobile 환경에 맞는 반응형 레이아웃을 구현하여
다양한 기기에서 편리하게 쇼핑할 수 있도록 구성하였습니다.
```

## ✨ 주요 기능

- 메인 및 상품 관련 페이지 구현
- 로그인 페이지 및 사용자 입력 기능 구현
- 상품 옵션 선택 및 상품 정보 탐색 기능 구현
- 상품 문의(Q&A) 기능 구현

- 연령별·상황별 상품 추천을 고려한 콘텐츠 구성

## ⭐ 주요 구현 내용

### 01. 상품 옵션 선택 및 탐색 기능

```text
→ 상품을 선택할 때 필요한 옵션을 확인하고 선택할 수 있도록 구현하였습니다.

상품 정보와 옵션을 구분하여 제공하고,
사용자가 원하는 조건에 맞춰 상품을 선택할 수 있도록 구성하였습니다.
```

#### 💡 셀프 코드리뷰 & 배운 점

- **상품 옵션 선택 기능 구현**: 상품을 구매하기 전 필요한 옵션을 선택할 수 있도록 구성하면서 사용자 입력에 따라 화면을 제어하는 방법을 익혔습니다.
- **상품 정보의 직관적인 구성**: 상품명과 가격, 옵션 등 구매에 필요한 정보를 구분하여 배치하고 사용자가 필요한 내용을 쉽게 확인할 수 있도록 고민하였습니다.
- **앞으로의 보완점**: 옵션 선택에 따른 가격과 재고 등 상품 정보의 변화를 함께 관리하고, 선택하지 않은 옵션이 있을 때의 예외 처리까지 고려하여 구매 과정의 완성도를 높이고 싶습니다.

### 02. 로그인 기능

```text
→ 사용자가 로그인 페이지에서 계정 정보를 입력할 수 있도록 구현하였습니다.

로그인에 필요한 입력 요소를 구분하고,
사용자가 기능을 쉽게 이해하고 이용할 수 있도록 화면을 구성하였습니다.
```

#### 💡 셀프 코드리뷰 & 배운 점

- **로그인 화면 구현**: 아이디와 비밀번호 입력 영역 및 관련 메뉴를 구성하면서 사용자 입력을 처리하는 기본적인 흐름을 익혔습니다.
- **사용자 편의성 고려**: 로그인과 회원가입, 아이디 및 비밀번호 찾기 등 관련 기능으로 이동할 수 있도록 구성하여 접근성을 높이고자 하였습니다.
- **앞으로의 보완점**: 실제 서비스에서는 입력값 검증과 로그인 실패 안내, 비밀번호 보안 및 서버 인증 과정을 함께 고려하여 로그인 기능을 개선하고 싶습니다.

### 03. 상품 문의(Q&A) 기능

```text
→ 상품에 대한 문의를 확인하고 작성할 수 있도록 Q&A 영역을 구성하였습니다.

상품 정보뿐만 아니라 구매 전 궁금한 사항을 확인할 수 있도록
문의 관련 콘텐츠를 제공하여 구매 과정에서 필요한 정보를 보완하였습니다.
```

#### 💡 셀프 코드리뷰 & 배운 점

- **문의 기능 구현**: 상품 문의 영역을 구성하면서 쇼핑몰에서 상품 정보 외에도 사용자와 판매자 간의 정보 전달이 중요하다는 점을 배웠습니다.
- **정보 구조 설계**: 상품 정보와 문의 콘텐츠를 구분하여 배치하고 사용자가 필요한 정보를 쉽게 문의 할 수 있도록 구성하였습니다.
- **앞으로의 보완점**: 문의 작성과 목록 조회, 답변 상태 표시 등 기능별 동작을 명확하게 구분하고 입력값 검증 및 예외 처리를 보완하고 싶습니다.

## 📝 회고

영유아 쇼핑몰을 기획하고 구현하면서 상품을 단순히 나열하는 것보다 사용자가 필요한 정보를 빠르게 찾고 편리하게 선택할 수 있도록 정보 구조를 설계하는 과정이 중요하다는 것을 배웠습니다.

특히 상품 옵션 선택과 로그인, Q&A 기능을 구현하며 쇼핑몰에서 필요한 기본 기능과 사용자 흐름을 고민해 볼 수 있었습니다. 또한 반응형 레이아웃을 적용하면서 화면 크기에 따라 콘텐츠 배치와 사용성이 달라질 수 있다는 점을 경험했습니다.

앞으로는 상품 정보와 사용자 입력에 대한 예외 처리를 보완하고, 접근성과 웹 표준까지 고려하여 더욱 편리하고 완성도 높은 쇼핑몰을 구현하고자 합니다.
